# 공동 코드에서 담당한 변경

여기에는 팀 공통 파일 전체 대신 Potato-Gamja(Gamja)의 관련 변경을 담았습니다. 파일별 목록은 [기여 근거](../docs/CONTRIBUTIONS.md)를 참고하세요.

- 각 패치는 표시된 원본 커밋의 **첫 번째 부모 → 해당 커밋** 차이입니다.
- 이 브랜치의 모든 파일을 만드는 순차 설치 패치가 아닙니다. 패치마다 기준 커밋이 다르고 서로 겹치는 변경이 있을 수 있습니다.
- 공백·빈 줄만 바뀐 차이는 제외했습니다. `+` 줄은 해당 커밋의 추가, `-` 줄은 삭제, 공백으로 시작하는 줄은 팀 코드의 문맥입니다.
- 초기 등록·팀원 동기화 커밋과, 팀원이 먼저 추가한 파일을 본인이 다시 가져온 추가분은 제외했습니다.
- 작성자 명의만으로 실제 설계·구현자 전체를 보증하지 않습니다. 원본 커밋과 담당 설명을 함께 확인해 주세요.

## 읽어볼 변경

게임 진행의 세션 통합은 `Assets/Scripts/Flow/GameFlowController.cs`, 방 참가·재접속은 `Assets/Scripts/Flow/LobbyNetworkCoordinator.cs`, 원격 상태 반영은 `Assets/Scripts/Network/RemoteGameSession.cs`의 파일별 링크에서 볼 수 있습니다. `IGameSession` 등 팀원이 작성한 인터페이스와 서버 구현 전체는 개인 구현 파일로 수록하지 않습니다.

총 41개 공동 파일의 변경을 47개 커밋별 패치로 묶었습니다.
